# SignBridge

SignBridge is a Flask-based web application for Sign Language recognition, hidden direct-URL Full-Control Admin Panel, and communication between deaf and hearing individuals.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Access the Admin Panel directly via URL (not linked publicly):
   `http://127.0.0.1:5000/admin/`
